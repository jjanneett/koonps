# 남면분소 직원 근무현황표

태안해안국립공원사무소 남면분소용 HTML5 · CSS · JavaScript 단일 페이지입니다. 외부 UI 라이브러리, API, 데이터베이스 없이 동작합니다.

## 실행

Node.js 24 이상에서:

```sh
cd /workspace/koonps
npm ci --cache /workspace/.npm-cache
npm start
```

서버의 기본 포트는 3000입니다. 변경하려면 `PORT=4000 npm start`를 사용하세요. 실제 웹 호스팅에는 `index.html`, `css/`, `js/`, `assets/`만 배포하면 됩니다. 이 프로젝트에는 빌드 과정이 없습니다. 로컬 저장소가 안정적으로 동작하도록 HTTP 또는 HTTPS로 실행하세요.

## 기능

- 960px 화면을 기본 기준으로 한 흰 배경의 반응형 화면. 모바일에서는 표 영역을 가로로 스크롤합니다.
- 대한민국 시간대(`Asia/Seoul`)의 오늘 날짜와 요일. 페이지를 열어둬도 30초마다 갱신합니다.
- 직원 추가·수정·삭제, 같은 직책의 셀 병합, 해당 직책의 마지막 직원 뒤에 삽입. 새로운 그룹은 사회복무요원 위에 삽입합니다.
- 직책 추가·이름 수정·삭제. 직원이 있는 직책을 삭제할 때 다른 직책으로 이동시켜 직원 정보를 유지합니다.
- 병합된 직책 드롭다운은 확인 후 그룹 전체에 적용됩니다. 개별 직원의 직책은 행의 `⋮ → 수정`에서 변경하세요.
- 근무·비고 드롭다운, 직접 입력과 파랑·빨강·검정 글자 색. 팝업 밖 클릭, 닫기 버튼, Escape는 입력을 취소하고 `완료`는 저장합니다.
- 현재 브라우저에 자동 저장, JSON 백업·복원, 전화번호 링크, 인쇄용 화면.
- 로고 클릭으로 PNG/JPG/WEBP 등록(5MB 이하). 흰 여백을 정리해 표시하며 등록한 이미지는 백업에도 포함합니다.

### 인원 집계 (`personnel`)

| 항목 | 계산 |
| --- | --- |
| 전체 | 등록된 직원 수 |
| 근무 | 사무실, 체험학습관, 야영장, 환경 및 시설물 관리, 탐방운전 선택 인원 |
| 휴무 | 휴무 선택 인원 |
| 기타 | 연가·병가·공가 선택 인원 + 비고의 당직·당직휴무 선택 인원 |

요청한 합산 방식에 따라 `기타`의 두 조건을 만족하는 직원은 두 번 집계됩니다. 근무와 기타에도 동시에 포함될 수 있으므로 각 항목의 합이 전체와 일치하지 않을 수 있습니다. 직접 입력한 항목은 집계하지 않습니다. 화면의 `기타` 옆 안내 버튼에서도 확인할 수 있습니다.

### 데이터 및 로고

실제 직원 명단이 제공되지 않아 처음에는 빈 표가 표시됩니다. 직원은 추가 시 사무실 근무로 등록됩니다. 데이터는 브라우저·사이트 주소별로 보관되며 서버나 다른 기기에 자동 공유되지 않습니다. 브라우저 데이터를 삭제하기 전 백업해 주세요. 백업 파일에는 이름, 전화번호, 근무 정보가 포함됩니다.

`assets/logo.png`는 첨부 이미지를 참고해 이미지 도구로 준비한 **임시 헤더 로고**입니다. 원본 파일을 실행환경에서 직접 읽을 수 없었고 도구가 디자인을 재구성했으므로 원본과 동일한 파일이 아닙니다. 정확한 원본은 화면 왼쪽 상단 로고를 클릭해 등록하거나 `assets/logo.png`를 원본 PNG로 교체하세요.

## 검증

```sh
npm test
npm run test:ui
```

단위 테스트는 인원 산식, 직책별 배치, 한국 날짜 경계와 백업 검증을 확인합니다. Playwright 테스트는 직원·직책 관리, 드롭다운 색상, 팝업, 자동 저장, 백업·복원, 로고 업로드, 모바일과 인쇄 화면을 브라우저에서 확인합니다.

클라우드 환경에는 `/usr/bin/chromium`이 설치되어 있습니다. 다른 환경에서는 `CHROMIUM_PATH`로 Chromium 실행 파일을 지정하거나 `npx playwright install chromium`으로 브라우저를 설치하세요. Playwright는 테스트 시 개발 서버를 시작합니다.

## 구조

```text
index.html             화면 구조
assets/logo.png        기본 로고
css/style.css          반응형·인쇄·팝업 스타일
js/data.js             옵션, 집계, 직원 배치, 백업 검증
js/app.js              화면 및 사용자 동작, 저장
scripts/server.mjs     의존성 없는 개발 서버
tests/                 단위·브라우저 테스트
```
